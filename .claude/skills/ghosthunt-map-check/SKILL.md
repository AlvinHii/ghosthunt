# 鬼抓人 ASCII 地圖檢查

使用時機：使用者給一張《鬼抓人》地圖（.md，裡面有 `## 1F`、`## 2F` 底下的 ```text 程式碼區塊），要你檢查、挑問題或修正。

不要相信地圖檔自己的「自我檢查清單」，每一項都用程式重新驗證。

## 步驟

1. 把上傳的檔案複製到一個空資料夾，腳本放在另一個資料夾，用 `python3 -I` 執行。
2. 抽出 1F、2F 的格子（每列補空白到同樣寬度）。座標寫成 (x, y)：x 從左數第幾欄、y 從上數第幾列，都從 0 開始，回報時先講清楚這個慣例。
3. 跑下面所有檢查，結果分成「對的」和「有問題的」，問題一定附座標。
4. 再對照遊戲規則和 AI 鬼的邏輯挑相容性問題（見「規則」）。
5. 在專案裡：這個 skill 檢查的是別的 AI 畫的原始 .md。通過以後再用 `tools/convert_ai_maps.py` 轉檔、`tools/pve_map_check.py` 做完整檢查。
6. 使用者要修：用程式改格子（不要手打整張圖），改完重跑全部檢查，再更新檔案裡的圖例、施工說明和自我檢查清單；輸出成「<原名>_修正版.md」。

## 腳本

`scripts/check_map.py` 會跑完下面「檢查」的大部分項目，並把結果分成「對的／參考」和「有問題的」：

```
python3 -I scripts/check_map.py <地圖.md> --low dpsv --max-line 20
```

`--low` 填該圖家具表裡 1 格高（看得穿）的家具字母。腳本沒辦法判斷的項目要自己看：圖例有沒有定義每個符號、樓梯洞口哪一端是上樓口（腳本只列出洞口旁的可走格）、方塊材質那些「規則」。

## 符號

`#` 室內牆、`%` 戶外圍牆／樹籬、`+` 矮欄杆、`,` 戶外地面、`.` 室內地板、`D` 單門、`W` 雙開門的一半、`O` 空門口、`G` 大門候選、`Q` 終端機候選、`E` 電源候選、`B` 木桶、`C` 可推倒櫃子、`h` 蹲伏小洞、`H` 暗格、`1` `2`… 地洞兩端、`>` `<` `^` `v` 樓梯（箭頭是往上爬的方向；往下用小寫 `v`，大寫 `V` 也認。家具表不能再用 `v` 當家具，撞到要換字母）、`=` 2F 樓梯洞口、`K` 鬼房、`I` 鐵欄杆門、`J` 監獄、`S` 出生點、小寫字母是家具（高度看該圖的家具表）。圖例沒定義的符號要回報。

## 檢查

- 尺寸：兩層列數相同、每列寬度相同。
- 數量：G、Q、E、B、C、h、H、地洞對數、K、J、S、樓梯格數，跟檔案自己寫的數字比對。
- 連通：從 `S` 用 BFS 走（可走：`,.JKSEQ12><=DWOIGh`），列出走不到的格子。
- 封閉：可走的格子不能碰到空白（地圖外），`G` 例外。
- 牆缺口：室內 `.` 直接上下左右相鄰戶外 `,`，就是牆少了。
- 門：每個 `D` `W` `O` `I` 前後兩側都要是可走格，不能是家具（逃生者不能跳，門前一格家具就是死門）。
- 小洞與暗格：`h` 兩側可走、另兩側是牆；`H` 三面是牆、一面是入口，而且入口對面那格（之後要挖空）的另外三邊也要是牆，不能在最外圈。
- 樓梯：1F 每個樓梯格在 2F 同位置要是 `=`；2F 洞口除了上樓那一端，三面都要有 `+`。
- 大門 `G`：每扇 3 格寬（連續 3 個 `G`），外面是場地外，中間那格往內 2 格要是空地（放讀卡機；跟遊戲的讀取器一樣只看中間那格）。2F 可以有大門，遊戲會在外面蓋陽台＋梯子；梯子落地的那一塊（往外 1～6 格、左右 2 格）在 1F 要是場地外，不然只有陽台沒有梯子。
- 櫃子 `C`：2 格內要有開口 `O`，放在門旁邊沒用。
- 監獄 `J`：不能畫成有門的房間（旁邊不能有 `D`、`W`）。
- 木桶每局隨機放，不用檢查數量。
- 地洞：每個數字剛好 2 個；回報直線距離和「從地面走要幾格」（BFS，不經過 `h`）。
- 距離：鬼房中心到監獄、到出生點的直線距離。
- 直線視野：1F 每列、每欄連續「看得穿」的格子不能超過 20 格。看得穿 = 地面、地板、`JKSE12=`、樓梯、1 格高的家具、`B`；牆、2 格以上家具、門、`h` 都擋。2F 若是刻意的高視野平台，可以例外但要說明。

## 規則（相容性）

- 牆、樹籬、欄杆不能用真人看得穿、AI 視線會被擋的方塊：鐵欄杆、樹葉、玻璃、銅格柵。圍牆用實心方塊，欄杆用柵欄（碰撞 1.5 格，誰都跨不過）。
- 燈要能被停電關掉：用接電源的銅燈泡或紅石燈，不要用燈籠、海燈籠、蛙鳴燈。
- 暗格是 1.5 格高、要蹲著進去（凹槽 `Y+1` 放上半磚），入口不要用垂根、藤蔓偽裝。
- 家具 `Y+0` 必須是完整方塊或柵欄、牆，不能是半磚或樓梯（會被走上去）。
- 戶外多的地圖要提醒：AI 巡邏要靠自動分區；夜晚或停電的地圖要擋自然生怪。
- 特殊機制要寫清楚 AI 怎麼接：藥水效果對怪物無效（改走「看不到人」）、超過 16 格的聲音要做成全圖聲音、跨樓層的聲音要開例外。
- 大部分門是單門時，提醒卡門規則要決定單門能不能卡。

## 修正時的原則

- 用柱子、樹這類 3 格高的 1×1 物件切斷長直線，放在周圍 8 格都是空地、2 格內沒有特殊格的地方；放完要確認連通沒變。
- 加欄杆讓走道變成 1 格寬時，優先加寬平台或把木桶這類東西移開，並在清單裡註記。
- 修完把「改了什麼」逐項附座標寫進自我檢查清單，並列出需要使用者確認的假設（例如樓梯方向）。
