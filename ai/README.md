# 鬼 AI 的自我對弈訓練（ai/）

目標：用強化學習訓練鬼的「高層決策」（沒看到人的時候接下來去哪裡、做什麼），之後匯出成 ONNX 接回插件，
取代 `GhostBrain.decideUtility` 的打分數；出錯、逾時、沒有模型就退回原本的規則型大腦。
抓人、揮拳、尋路、開門、手電筒這些底層照舊（插件的 AiGhost）。

只做 mall2、hospital（2026-11-24 使用者決定）。

## 資料夾

| 路徑 | 內容 |
|---|---|
| `sim/world.py` | 讀 `src/main/resources/pve-maps/<地圖>.txt`：走得到的格子、擋視線、區域、興趣點、全部兩兩的走路距離（快取在 `%LOCALAPPDATA%\ghosthunt-ai\`，每張圖約 280 MB） |
| `sim/game.py` | 一局 PvE 的模擬（每步 0.25 秒）。鬼分反射層（看到就追、前搖／揮空／疲勞、追丟去最後看到的位置、感應）和高層決策；規則型逃生者 |
| `sim/config.py` | 讀插件的 `config.yml`（數值只有這一份） |
| `sim/run.py` | 規則型鬼 vs 規則型逃生者跑很多局的統計 |
| `train/model.py` | 策略網路：每個區域用同一個小網路打分數＋GRU 記憶（換地圖也能用） |
| `train/envs.py` | 平行跑很多局（multiprocessing） |
| `train/ppo.py` | PPO 訓練（只訓練鬼，逃生者固定規則型）；可以從中斷的地方繼續 |
| `export/onnx_export.py` | 匯出 ONNX，並比對 PyTorch 和 ONNX 的輸出 |
| `tools/replay.py` | 重播 HTML（兩層樓並排，可以播放） |

## 怎麼跑

```
python -m ai.sim.world mall2 hospital                       # 建距離快取（第一次約 20 秒）
python -m ai.sim.run --map mall2 --games 1000 --replays 3   # 規則型對打 1000 局（約 30 秒）
%USERPROFILE%\.venvs\ghosthunt\Scripts\python -m ai.train.ppo --run ghost_v1 --hours 6
%USERPROFILE%\.venvs\ghosthunt\Scripts\python -m ai.export.onnx_export --run ghost_v1
```
訓練用的 Python 環境在 `%USERPROFILE%\.venvs\ghosthunt`（PyTorch CUDA，放在 OneDrive 外面免得同步好幾 GB）。

## 觀察和動作（鬼的策略看到什麼、能做什麼）

**觀察**（`OBS_DIM = 64 × 15 + 14`，2026-11-24 從 12＋12 加大；舊模型用 `model.load_expand` 接著練）：每個區域 15 個數字，加上 14 個全域數字。只放鬼在遊戲裡本來就知道的東西，**沒有透視**：
- 區域：人可能在這裡的信念（看到人、聽到聲音、感應會提高；沒看到人、時間經過會擴散）、最近一次聽到聲音多久了、多久沒去、鬼在不在這裡、走過去多遠、樓層、是不是死路、大小、有沒有總電源、終端機、大門（倒數中標 2）、監獄；（新）多久前在這裡看到人、追丟後的粒子有幾成在這裡、有幾個暗格。
- 全域：時間、有沒有電、自由／被關／逃出的人數比例、四個特殊動作能不能用、鬼在幾樓、多久沒接觸人、授權了幾張卡；（新）多久沒看到人、粒子還剩幾成。

**動作**：去第 i 個區域（最多 64 個）、去最近的聲音、關電源、弄壞倒數中的大門、守監獄、（新）原地等 4 秒轉頭看、跟著粒子找。不能用的動作直接遮掉。

## 反射層第二版（2026-11-24，`ai-ghost.sim-reflex: 2`，預設）

照插件 AI 鬼第三版補的（`docs/AI鬼邏輯.md` 6.3、6.6）：
- 繞前堵：每次開始追擲 `intercept-chance`（普通 0.5），每秒猜對方往哪個出口／目標跑，找他路上鬼先到 0.5 秒的格子。
- 追丟後撒 64 顆粒子（60% 往離鬼遠、25% 往下一個遊戲目標、其他亂走，每 0.5 秒走 3 格，鬼看得到的刪掉，40 秒或剩不到 6 顆放棄）；動作「跟著粒子找」去粒子最多的區域。
- 到了最後看到的位置照證據查暗格（在入口 3 格內、5 秒內、之後沒聲音 ×2.5；8 格外 ×0.3）；先走到入口再打開。
- 到一個區域轉頭張望 1.5 秒；站著等的時候每 0.5 秒轉 90 度。

逃生者也改了（`REALISM`）：視野 110 度（之前 360 度都看得到鬼），3 格內不分方向；每 0.5 秒回頭看一圈的機率 0.1，心跳在響 0.4。
規則型對打（各 400 局、3 人）：每人逃出率 mall2 0.28 → 0.28、hospital 0.34 → 0.32——幾乎沒變，因為被抓的人 98% 是「看到鬼、正在逃」的時候被追上，
鬼贏在追人和逃生者被逼到角落，不在偷襲。

## 用真人對局校正（2026-11-24）

之前的模擬器鬼太強（規則型逃生者每人只逃出 5%），真人 4 局普通 2 人局（test-server 的 stats.log，2026-11-23）每人逃出約 62%。修了這些：
- 三個 bug：鬼追人時頭沒盯著目標（人一閃到旁邊就跟丟）、前搖時站著不動而且一律算揮空、逃生者被逼到角落時移動額度一直存著（之後一步瞬移好幾格）。
- 鬼的速度：插件 `AiGhost.steer` 每 tick 走「速度屬性 × 0.57」格，速度屬性 = base-speed ×（1＋人數加成），所以每秒 11.4 × base-speed ×（1＋加成）：0.45、3% 是 5.3 格（逃生者跑步 5.6），模擬器之前當成 5.6 ×（1＋加成）。
- 逃生者的甩鬼手段：卡門、障礙物、推櫃子、煙霧彈、加速藥水、手電筒（`REALISM['tools']`）。只讓逃出率 0.04 → 0.09。
- **聰明地逃**（`REALISM['smart-flee']`，影響最大）：之前逃跑只會「往離鬼最遠的那一格」，很容易自己跑進角落；改成每秒挑一個「比鬼先到的餘裕大、離鬼遠、不是死路」的地方跑過去。0.025 → 0.575。
校正後（smart-flee 0.85、tools 0.8）速度 0.45、2 人：每人逃出 0.55（真人 0.62，只有 4 局，誤差很大）。之後真人局多了要再校正。

**AI 鬼的速度（2026-11-24 使用者：目標普通難度真人每人逃出約 50%，鬼一定要比人快）**：`python -m ai.tools.speed_sweep`，各 1000 局、規則型鬼：

| base-speed | 追人每秒格數（2～3 人） | 一般玩家 | 謹慎玩家 | 2 人／3 人（一般） |
|---|---|---|---|---|
| 0.45（原本） | 5.3（比人慢） | 0.64 | 0.73 | |
| 0.56 | 6.6 | 0.53 | 0.65 | 0.44／0.63 |
| 0.58 | 6.8 | 0.49 | 0.58 | 0.39／0.58 |
| **0.59（採用）** | **6.9** | **0.43** | **0.55** | 0.31／0.55 |
| 0.60 | 7.0 | 0.40 | 0.52 | 0.28／0.52 |

0.45～0.49 幾乎沒差（鬼比人慢或差不多，追不上），超過才開始有效。2 人局比 3 人局難很多，之後可以考慮依人數分開調。

**加上「守下一個目標」（`guard-objective`）之後**（2026-11-24，各 800 局）：0.53 → 一般 0.46／謹慎 0.67；**0.56 → 0.38／0.63（平均 0.51，採用）**；0.59 → 0.30／0.50。

**追人技巧的實驗（都沒用，沒寫進插件）**：追丟後照移動方向多追 8 格 0.268、預測他往哪裡逃 0.245、每次都算繞前堵 0.248、追丟後 4 秒維持追人速度 0.246（基準 0.242，各 400 局）。
跟丟的原因：轉角視線被擋 67%、煙霧／手電筒 16%、跑太遠 15%、卡門 2%。只有整體速度有用（搜尋速度 0.9 → 1.0：0.205）。
`chase-heading`、`chase-predict`、`lost-chase-time` 留在模擬器當實驗開關（預設關）。

**獎勵**（照計畫，先不加引導分數）：抓到一人 +1、淘汰 +0.5、全部抓完 +3、逃生者每完成一個主線目標（開電源、第一張卡、授權、刷卡、大門打開）−0.3、每逃出一人 −3。

## 模擬器還沒有的東西（跟插件不一樣的地方）

- 小鬼、道具（手電筒、煙霧彈、加速藥水、掃描器、障礙物、急救包、硬幣、販賣機）
- 門的開關和卡門、推倒的櫃子、蹲伏小洞（逃生者鑽洞）、地下通道的撬開動作（只當成比較長的路）
- 支線逃生路線（貨梯、直升機、下水道）、監視器、廣播、區域配電箱、鐵捲門、上鎖的門（屋頂那一區走不到）
- 搬卡、困難模式的倒地救援
- 鬼的感知簡化：聽到的聲音只看直線距離、同一層；視野 120 度、視線用格子算
- 逃生者比真人有效率：知道地圖、會分頭翻木桶。用 `game.REALISM` 調（走路、停下來看、走錯路、反應時間），之後拿真人的 `stats.log` 校正

所以模擬器的一局（約 4 分鐘）比真人短很多，**數字只能看大方向**。
