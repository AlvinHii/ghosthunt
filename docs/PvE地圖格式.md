# PvE 固定地圖格式

PvE 地圖可以是「固定格局」：照一份文字平面圖蓋，**每局開始前重蓋一次**，重新隨機挑：

- 大門 2 扇（從 `G` 候選裡挑，條件：不同樓層 → 相距 ≥ `gate.min-distance` → 靠不同樓梯，挑不到會逐級放寬；
  候選全在同一層的話只看距離）
- 保全室 2 間（從有 `Q` 的房間裡挑，優先不同樓層、離得遠）
- 木桶（整張地圖隨機，靠牆、不擋路，數量依面積 `pve.barrel-area`）
- 電源開關（遊戲開局時從所有 `E` 裡挑一個）

地圖檔放在 `plugins/GhostHunt/pve-maps/名字.txt`（插件附的地圖第一次啟動時會複製過去）。
指令：`/gh maps` 看有哪些地圖，`/gh build pve [名字] [種子]` 蓋，`/gh build pve random` 用舊的隨機產生器。
`config.yml` 的 `pve.map` 是預設地圖，`pve.reroll-each-match: false` 可以關掉每局重蓋。

檢查工具：`python tools/pve_map_check.py <地圖檔> --png 圖.png`（走不走得到、樓梯、暗格、長直線視野、空曠區域、數量）。

## 檔案結構

```
name: 夜間辦公園區              ← 顯示用名稱
type: mixed                    ← indoor / outdoor / mixed（只是標記）
description: 一句話說明

[1F]
%%%%%%%%%%%%
%,,,,,,,,,,%
...
[2F]                           ← 沒有 2F 就不用寫；每層的圖大小一樣、上下對齊
                               （[1F]／[2F] 下一行就是第一列；上面整列空白的列也要留著）
...

[furniture]
t = oak_log, oak_leaves, oak_leaves       # 由下往上，幾個就幾格高
l = dark_oak_fence, dark_oak_fence, lantern | light   # | light：頂上加一盞跟著電源亮暗的燈

[palette]
wall = smooth_quartz           # 牆
outer-wall = light_gray_concrete   # 碰到場地外面的牆（沒寫就跟 wall 一樣）
ceiling = smooth_stone         # 天花板、屋頂
hedge = dark_oak_leaves        # %（3 格高）
hedge-base = moss_block        # % 底下的地面
fence = dark_oak_fence         # +（1 格高，會自動接起來）
outdoor = grass_block, moss_block      # , 的地面（第一個為主，其他偶爾混進去）
deck = oak_planks              # 2F 的 , 地面（陽台、天橋；沒寫就跟 outdoor 一樣）
path = stone_bricks, andesite          # ; 的地面
room-floors = white_concrete, cyan_wool, ...   # 室內每間房間輪流用（認路用）
door = spruce                  # 門的木頭

[sounds]                       ← 可以不寫：地圖音效（要玩家裝資源包，見下面「音效」）
global = hydro.global 0.35
zone = hydro.turbine 0.8 1F 2,27 13,36
```

地圖區塊裡一個字元一格，**不能寫註解**；其他區塊 `#` 後面是註解。

## 音效（`[sounds]`）

聲音檔放在 `resourcepack/assets/ghosthunt/sounds/`，在 `resourcepack/assets/ghosthunt/sounds.json` 取名字（例如 `hydro.global`）。
`./gradlew build` 會把 `resourcepack/` 打包進插件，插件自己開網頁伺服器送給玩家（`config.yml` 的 `resource-pack`；`/gh pack` 重送）。

| 寫法 | 意思 |
|---|---|
| `loop = 30` | 環境音多久重播一次（秒，跟音檔一樣長） |
| `global = 名稱 音量` | 全場一直播的底層環境音 |
| `zone = 名稱 音量 樓層 x,z x,z [x,z x,z …]` | 玩家站在這些方塊範圍裡時播（兩個角一組，可以好幾組；座標＝地圖格子座標；先寫的優先） |
| `tunnel = 名稱 音量` | 在地下通道裡時播 |
| `random = 名稱 最短秒 最長秒 音量` | 隨機間隔的事件音，全場都聽到 |
| `power-on = 名稱 音量`／`power-off = 名稱 音量` | 電源打開／被關掉（停電、鬼關電源）時 |

- 名稱沒寫命名空間就是 `ghosthunt:`；也可以用原版的，例如 `minecraft:block.beacon.deactivate`。
- 音檔是立體聲的話，Minecraft 不會依距離變小聲，所以插件是直接在玩家身上播、只給他聽；「區域」靠玩家站的位置決定。
- 純裝飾：AI 鬼聽不到這些聲音。玩家沒裝資源包就是沒聲音，不影響遊戲。

## 符號

| 符號 | 意思 | 蓋出來 |
|---|---|---|
| `.` | 室內地板 | 房間地板（每間不同色），上面有天花板（上一層沒東西就蓋屋頂） |
| `,` | 室外地面 | `outdoor` 材質，上面是天空；在 2F 就是陽台 |
| `;` | 室外路面 | `path` 材質 |
| `#` | 牆 | 4 格高 |
| `%` | 高樹籬／圍牆 | 3 格高（樹葉會設成不會消失） |
| `+` | 矮欄杆 | 1 格高柵欄，擋路不擋視線 |
| `D` | 一般門 | 不能卡門 |
| `W` | 雙開門（2 個並排） | 可以卡門（`b.doors`） |
| `O` | 開口 | 1～2 格寬：可以放障礙物（黃色地毯）；3 格以上：單純的缺口 |
| `I` | 鐵欄杆門 | 鬼房的門 |
| `h` | 蹲伏小洞 | 下面空、上面半磚 |
| `H` | 暗格入口 | 蹲伏小洞＋後面那格挖成躲藏空間（後面要是 `#`/`%`，躲藏空間另外三邊也要是牆） |
| `^ v < >` | 樓梯 | 畫在下層，箭頭＝往上走的方向，5 格長 2 格寬；下面填實 |
| `=` | 上層的樓梯開口 | 前 4 格開洞，第 5 格是樓梯頂；洞旁邊走得到的格子自動放欄杆 |
| `1`～`9` | 地下通道出入口 | 只能在 1F，同數字一對；地下自動挖彎曲通道，活板門＋梯子 |
| `G` | 大門候選 | 在最外圈；往內 2 格要是空地（放讀卡機）；沒挑到的補成牆 |
| `Q` | 保全室終端機候選 | 室內靠牆；挑到的放終端機，那間房變保全室（藍色地板） |
| `E` | 電源開關候選 | 靠牆；旁邊是樹籬／欄杆的話補一個鐵方塊配電箱 |
| `S` | 出生點 | 出生點＝S 和旁邊 8 格 |
| `K` | 鬼房地板 | 鬼從中心出生；要用牆和 `I` 圍起來 |
| `J` | 監獄籠子內部 | 外面一圈是地面的格子自動蓋鐵欄杆（是牆的就留著當籠子的一邊）；再外面一圈要能站人（救人範圍 4.6 格） |
| `C` | 可推倒的櫃子 | 2 格內要有 `O` 開口，推倒會擋住那個開口 |
| 小寫字母（`h`、`v` 除外） | 家具 | `[furniture]` 定義；上面不能走 |

## AI 鬼怎麼用

- 尋路圖開局時從方塊建（`NavMap`），跟隨機產生的地圖一樣，不用額外標記。
- 巡邏點：每個室內區域一個；戶外大區域切成 10×10 的小塊，每塊一個（`RoomType.YARD`）。
- 暗格：`H` 的躲藏空間記成暗格（AI 搜尋時會擲骰去打大洞口）。

## 設計建議（`pve_map_check.py` 會提醒）

- 走道至少 2 格寬，斜角不算連通；家具旁邊留 1 格。
- 每個區域至少 2 個出口；室內房間 6×6～14×14。
- 不要有超過 20 格的長直線視野（霧 14 格，鬼看得到前方）；戶外無遮蔽空地不要超過 12×12。
- 木桶會沿牆放，牆邊要留空間（木桶位置要求往內 2 格是空地，不會把路擋窄）。
