# 今晚測試指南

## 開場前（管理員做一次）

1. 雙擊 `test-server/start.bat` 啟動伺服器（第一次會載入霧的資料包）。
2. 伺服器視窗輸入 `op 你的ID`（要下指令的人才需要）。
3. 朋友連進來（原版 Minecraft 26.3，正版帳號）。
4. 管理員輸入：
   - `/ghosthunt build` 蓋一棟新大樓（約 1 秒）
   - `/ghosthunt selftest` 自我檢查（看到「完成，沒有錯誤」再開局）
   - `/ghosthunt start 鬼的ID nightmare`（或 `basic`；鬼的 ID 打 `random` 就隨機）

**線上所有人都會被拉進遊戲**，不想玩的人先下線。遊戲中途要停：`/ghosthunt stop`。下一局再 `/ghosthunt build` 換一棟（可以不換，開局會自動把場地復原）。

## 怎麼玩（開局時每個人也會收到說明）

**逃生者**
1. 到 **電力室** 右鍵牆上的 **拉桿**，站著不動 5 秒開總電源（兩個人一起更快）。門口告示牌寫著房間名稱。
2. 右鍵 **木桶** 翻東西（站 2 秒）：門禁卡（全場 2 張）、煙霧彈、加速藥水、手電筒、掃描器、障礙物。上面有鐵活板門的是上鎖箱，要撬 5 秒。
3. 拿著門禁卡右鍵大門旁的 **讀卡機（磁石）** 刷卡（要有電），大門倒數 25 秒後打開，穿過去就逃出。
- **F**：衝刺｜**蹲下**：鑽牆上半磚下的小洞（鬼過不去）｜拿著障礙物右鍵門口的 **黃色地毯**：擋門
- 被抓會關進監獄，隊友站在籠子旁邊就能救；第 2 次被抓淘汰。
- 翻箱子、開電源、刷卡、用掃描器都會發出聲音，附近的鬼會知道方向。

**鬼**
- 左鍵打到就抓到，每揮一次手會疲勞 1.5 秒（變慢、抓不到）。
- 畫面下方的箭頭＝附近逃生者做事的聲音方向。
- 右鍵拉桿：關一次電源｜右鍵倒數中的讀卡機：弄壞大門（每扇一次）｜右鍵障礙物：拆｜右鍵小洞：打大
- 門禁卡位置每 90 秒亮 5 秒，拿「搬卡」（終界之眼）右鍵：把卡搬走並鎖起來。
- 夢魘：拿「熄燈」（回聲碎片）右鍵，關燈 90 秒，看得到附近逃生者的紫色軌跡。

## 測的時候請注意

- 有沒有錯誤訊息、卡住、明明該能做卻做不了的事（例如翻箱子沒反應、刷卡沒反應）。
- 一局大概多久？太快還是太慢？（每局數據會記在 `test-server/plugins/GhostHunt/stats.log`）
- 鬼是不是太強或太弱？救人容不容易？
- 地圖會不會太大、太暗？霧（`/ghosthunt fog 8`）好不好用？
- 有任何不好玩的瞬間都記下來。

## 已知限制

- **整局流程只在沒有玩家的情況下測過**：場地準備、開電源、開大門用 `/ghosthunt selftest` 驗證過；真人互動（翻箱子、刷卡、抓人、救人、道具）程式寫好了，但今晚是第一次真正跑。
- 夢魘熄燈時的霧只有逃生者看得到；這需要伺服器重開過一次（載入霧的資料包）。
- 一般房間的燈只有 4 盞＋走廊的燈，有電時亮度 10、沒電時 1，可以在 `config.yml` 調 `map.normal-light-level`、`map.emergency-light-level`。
- 數值都在 `test-server/plugins/GhostHunt/config.yml`，改完 `/ghosthunt reload`（下一局生效）。這個檔是舊版產生的，**新的設定項目要刪掉這個檔再重開伺服器才會出現**（不刪也能玩，會用預設值）。
