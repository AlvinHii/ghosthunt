# AI 鬼第三版第 2～4 批＋購物中心家具：執行紀錄（2026-11-22 夜間）

使用者睡前授權（2026-11-22）：修完 AI 問題 → 第 2～4 批全做（第 17 項追擊加速不做）、可以重開 test-server、**不改現有平衡數值**（新功能的新設定用企劃的預設值）、購物中心家具照 md 家具表自己蓋。
下面是做的過程中自己決定的事（rulings），使用者可以推翻。

## 第 2 批（第 8、11～15 項）

| # | 決定 | 理由 |
|---|---|---|
| R1 | 「區域」= 房間（`Building.rooms`，每一格歸最近的房間中心），區域圖的邊 = 尋路圖上跨區的一般邊（不算蹲伏小洞、地洞）。 | 固定地圖沒有另外標走廊；房間中心已經有，最省事。開放大廳的區域交界不一定在門口。 |
| R2 | 「咽喉區」= 割點，或介數中心性 ≥ 0.5；巡邏 ×1.5。最小割（企劃第 12 項第三點）沒做。 | 區域圖只有 20～33 區，割點＋介數已經夠用；最小割要等「守大門」真的需要時再補。 |
| R3 | 死路房間沒有證據時，巡邏權重 ×0.3，而且**不進去、只走到入口往裡看**（轉頭張望）。證據 = 30 秒內的聲音、30 秒內看到人的位置、粒子 20% 以上在裡面。 | 企劃說「沒有證據就不進去」。權重直接設 0 的話有些店永遠沒人看；在門口看一眼比較像真人。 |
| R4 | 繞前堵：候選 = 對方所在區的每個出口（同一個相鄰區、4 格內的出口算一個）＋ 40 格內的下一個遊戲目標；softmax 溫度 0.35；「過去 1 秒變近多少」除以逃生者跑速，跟餘弦一樣在 −1～1。每秒重算一次。 | 企劃沒給溫度；變近的格數不除跑速會蓋過方向。 |
| R5 | 繞前堵只在「開始追」時擲一次（普通 50%、困難 100%、簡單 0）；堵到了（走到攔截點 1.5 格內）就改直追。 | 企劃「普通 50% 的機會會用」，每次追擲一次比每秒擲一次穩定。 |
| R6 | 退場埋伏：冷靜期一開始規劃一次。起點 = 最後看到的位置 → 追蹤粒子 → 最後一次真的看到人的地方（剛抓到人時 lastSeen 被清掉，原本會直接不埋伏）。走逃生者成本的最短路到下一個目標，路上第 10 格以後第一個「咽喉區的入口」（沒有就第一個區域交界）；埋伏點 = 入口那一區 1.5～5 格內、不在路上、從「入口前 6 格」和起點都看不到的格子，靠牆的優先。 | 「退場」那一步（先走到看不到的地方）合併成「埋伏點本身看不到」。 |
| R7 | 埋伏最多等 25 秒（`ambush-time`），走過去最多 30 秒；看到人、聽到聲音、感應、追丟後搜尋 → 結束埋伏。 | 企劃。 |
| R8 | 守讀卡機：有人授權、還有沒開的大門時，輪流守每一扇的讀卡機，守望點 = 同層 3～9 格、眼睛看得到讀卡機的格子；每次最多 40 秒，之後走開 20 秒再回來。優先度在關電源下面、守監獄上面。 | 企劃第 15 項；「最小割守望點」沒做（見 R2）。 |
| R9 | 關電源時機：價值 = 他們走回電源的平均秒數 − 鬼走過去的秒數 ≥ 15 秒（`cut-power-advantage`）；他們的位置只用鬼知道的（30 秒內看到的位置、追蹤粒子），不知道的人算 30 秒；**另外加了一條「電源開了 90 秒以後不管時機」（`cut-power-max-wait`）**。 | 不加的話鬼離電源遠就永遠不關，跟第二版差太多。 |
| R10 | 聲音沿路傳：關著的門每條邊 +2（穿過去 +4）、蹲伏小洞每條邊 +1（+2）、地洞每條邊 +2、障礙物 0；不分樓層（沿樓梯傳）。迎賓鈴照舊全圖、位置 ±3。 | 企劃第 8 項。地洞企劃沒寫，當成關著的門。 |
| R11 | 聽到的位置改成「傳播路徑上，離聲音 `noise-error`（3）格的那一格，至少離鬼 2 格」，不是企劃寫的「離鬼 6 格」。 | 離鬼 6 格的話，聲音在 15 格外時鬼只走 6 格就停下來張望，比第二版還笨。改成「沿路走到聲音附近」，一樣不會穿牆、會從聲音傳來的門口進去。 |
| R12 | Match.noise 的同層限制只對真人鬼的方向箭頭；AI 改成沿路傳（直線距離超過範圍的先跳過，省計算）。 | |

## 第 3 批（第 16、18～20 項）

| # | 決定 | 理由 |
|---|---|---|
| R13 | Utility：第二版的規則當「硬條件」，成立的目標分數 = 級數基本分（相鄰兩級差 2 倍）× 考量（0.5～1）× 個性權重；目前的目標 +15%；換目標後至少 1.5 秒（攻擊、追除外）。考量只做了三個：追（越近越高）、找最後位置、聲音（越新越高），其他是 1。 | 這樣「標準」個性跟第二版的順序完全一樣（測試搬過來全過），個性只改變「差不多」的情況，不會出現奇怪的行為。企劃表裡其他考量（粒子集中度、守監獄有人靠近）之後有資料再加。 |
| R14 | 困難選最高分；普通、簡單從最高分 90% 以內加權隨機。 | 企劃。級數差 2 倍，所以大部分情況其實還是固定的。 |
| R15 | 個性的數值照企劃表；「獵犬追擊加速 +10%」不做（使用者決定不做追擊加速）。埋伏者「每次追人都算繞前堵」，但簡單難度（intercept-chance 0）還是不堵。 | |
| R16 | 個性的線索：腳步聲音高（獵犬 ×1.25、埋伏者 ×0.8、守望者 ×0.65）、發現人時的吼聲（狼嚎、嗅聞、咆哮）。開局不告訴玩家是哪一種。 | 企劃說要讓玩家猜。 |
| R17 | 預設 `persona: auto`（每局用記憶裡的 Beta 分布抽）；指定個性的局不更新拉桿。 | 企劃第 18、21 項。 |
| R18 | 學習只用**真人逃生者**（`learn-from-dummies: false`），假逃生者的習慣不算。 | 不然 solo 測試會把記憶弄髒。 |
| R19 | 「被哪一招甩掉」的判斷用**真實位置**：追丟 5 秒時看對方在暗格裡、地洞裡、路線經過蹲伏小洞、在死路房間；煙霧彈（追丟前後 5 秒內被煙到）、迎賓鈴（追丟前 10 秒內響過）。30 秒內沒重新找到才記一筆。 | 鬼自己通常看不到招式本身。相當於真人鬼「這局結束後回想被怎麼甩掉」，只影響之後的機率，不會讓鬼在這次追逐中知道人在哪。 |
| R20 | 加成 = 上限 ×（1 − 0.5^次數）：第一次被甩後就有一半。蹲伏小洞的加成 = 打大洞口的成本 ×（1 − 加成）（更早決定打洞）；地洞 = 跟下去機率＋加成、有地洞出入口的區巡邏 ×（1＋加成）；死路 = 0.3 → 1，加成 ≥ 0.5 後也會進去看；迎賓鈴 = 有機率不理；煙霧彈 ≥ 0.5 = 被煙到時往最後看到的方向多走 6 格。第一次學會時逃生者畫面下方「你覺得那個東西好像記住了這一招……」。 | 企劃第 19 項；「改去監獄」沒做（不理迎賓鈴就好）。 |
| R21 | 熱點：看到人時每秒在那一格 +1（周圍 3 格線性遞減），區域熱度 = 區內格子的總和 ÷ 最熱的區；巡邏 ×（1＋熱度），開局第一個巡邏目標 ×（1＋3 × 熱度）。粒子偏向熱區沒做。 | 粒子偏熱區會讓推理更像「作弊」，先不做。 |

## 第 4 批（第 21、22、24 項）

| # | 決定 | 理由 |
|---|---|---|
| R22 | Thompson sampling：分數 = 1 − \|逃出比例 − 目標\|（簡單 0.7、普通 0.5、困難 0.3）；只有真人逃生者的局（solo 不算）、自動選的個性才更新。舊資料每局 ×0.85（只縮超過 Beta(1,1) 的部分）。 | 企劃。 |
| R23 | 路線預測只用在「繞前堵猜方向」的先驗（每個出口乘「從這區出去走到那區」的機率，再正規化）；粒子、埋伏還沒用。 | 粒子、埋伏要改純邏輯介面，先做最有用的一項。 |
| R24 | 自動調參：模擬器沒有大門、木桶，量不到逃出比例，所以目標改成「追丟後 30 秒內重新找到」照難度（簡單 85%、普通 92%、困難 97%）＋ 第一次接觸 60～120 秒；只搜尋粒子的三個參數（數量、往遠處逃的權重、聲音的高斯半徑），隨機搜尋。**只印建議值，不改 config**。 | 授權第 3 點：不改現有數值、列給使用者決定。 |

## 購物中心家具
