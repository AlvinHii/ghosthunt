# PvE 地圖生成 prompt

用法：把下面「Prompt」整段丟給其他 AI，最後一行填**地圖類型**（室內／室外／室內＋室外）和**主題**。它回的文字整份存成 `.txt` 或 `.md` 給我（一張地圖一個檔）。
我寫的讀取器會**照圖固定蓋出格局**，每局再從圖上標的「候選位置」隨機挑大門、保全室、電源；木桶整張地圖隨機放，不用畫。
拿到圖之後我會先用程式檢查（走不走得到、樓梯、死路、尺寸、視野），小錯我直接修，大問題再回頭跟你說。

---

## Prompt

```
你要幫一個 Minecraft 小遊戲設計一張地圖。遊戲是「鬼抓人」：2～3 個玩家（逃生者）要找門禁卡、開電源、
到保全室授權、刷卡打開大門逃出去；一隻電腦控制的鬼在場上巡邏、追人。逃生者靠轉角、門、小洞、暗格、
地下通道、遮蔽物甩開鬼。所有人都不能跳，遊戲是晚上、霧很濃（大約 14 格外看不到）。

地圖類型有三種（最後一行會指定）：
- 室內：一棟建築，2 層。
- 室外：整片戶外場地（例如公園、港口、工地、墓園、遊樂園），1 層，可以有幾個小屋；
  想要的話可以加一點 2F（瞭望台、天橋、陽台），用樓梯上去。
- 室內＋室外：戶外的庭院／街道，加上 1～3 棟建築（每棟 1 或 2 層），室內外都要有任務點，玩家要進進出出。

請用「文字格子圖」畫出來，規則如下，請嚴格遵守：

【格式】
1. 一個字元＝一格方塊（1×1）。只用半形 ASCII 字元，不要用全形、不要用 tab。
2. 每一層畫一張，各放在自己的 code block，標題寫「1F」「2F」。只有 1 層就只畫 1F。
3. 每一層的圖大小完全一樣、上下對齊（第 r 行第 c 個字元在每層是同一個位置），每一行字元數都一樣。
   2F 只畫有東西的地方（建築的 2 樓、陽台、天橋），其他位置用空白「 」。
4. 尺寸：寬、高各 40～64 格。外型可以不是矩形，場地以外用空白「 」。
5. 整個場地的最外圈一定要封起來：建築用牆 #，戶外用高圍牆／樹籬 %（大門候選 G 畫在外圈上）。

【符號】
  .  室內地板（上面有天花板）
  ,  室外地面（上面是天空，例如草地）；畫在 2F 就是陽台／屋頂／天橋（沒有屋頂，邊緣一定要用 + 或 # 圍起來）
  ;  室外路面（石磚路、柏油路；跟 , 一樣可以走，只是換材質）
  #  牆（實心，4 格高）
  %  戶外的高圍牆／樹籬／鐵絲網（3 格高，擋路也擋視線）
  +  矮欄杆／矮籬笆（1 格高，擋路但看得過去；大家都不能跳，所以過不去）
  D  一般門（1 格寬）
  W  雙開門（兩個 W 並排，玩家可以把它卡住，鬼要撞開）
  O  沒有門的門口／缺口
  I  鐵欄杆門（只用在鬼房的門）
  h  蹲伏小洞：畫在 # 或 % 上，只有 1 格高，要蹲著才過得去（兩側都要是地面）
  H  暗格入口：畫在 # 或 % 上，前面恰好 1 格是地面。H 後面（背對地面那一側）那一格要是 # 或 %，
     程式會把它挖成 1×1 的躲藏空間，所以那一格的另外三邊也都要是 # 或 %（牆至少 2 格厚）
  ^ v < >  樓梯：畫在下面那層，箭頭是「往上走」的方向，長度剛好 5 格、寬 2 格（並排兩條）
  =  上面那層的樓梯開口：對應樓梯的那 5×2 格畫 =（不能放東西；開口旁邊的地面程式會自動加欄杆）
  1 2 3 4  地下通道出入口（室內是地板活板門，室外可以當人孔蓋）：只畫在 1F，同一個數字是一對，程式會自動挖通道連起來
  G  大門候選：畫在最外圈的 # 或 % 上
  Q  保全室終端機候選：畫在「室內」房間裡靠牆的地板上（那間房就是保全室候選）
  E  電源開關候選：靠牆／靠圍牆的地面（室內、室外都可以，室外就是配電箱）
  S  逃生者出生點
  K  鬼房的地板（鬼開局被關在這裡）
  J  監獄籠子的內部（大約 4×4，被抓的人關在這裡）。程式會在 J 外面一圈蓋鐵欄杆，
     所以 J 外面那一圈要是地面，再外面還要有一圈地面讓隊友站著救人
  C  可推倒的櫃子候選：室內門口旁邊的地板（推倒會擋住門口）
  小寫字母 a～z（除了 h 和 v，它們是小洞和樓梯）：家具／物件，自己定義（見下面【家具／物件】）

【一定要有】
- 大門候選 G：至少 4 個，分散在不同區域，彼此距離遠（有 2F 的話兩層都要有）。
- 保全室候選 Q：至少 4 個，在 4 間不同的室內房間。室外地圖要放在小屋／警衛亭裡（至少 2 間有門的小屋，每間內部至少 4×4）。
- 電源開關候選 E：至少 4 個，分散。
- 地下通道：1～2 對，兩端相距至少 20 格，在不同區域。
- 蹲伏小洞 h：2～4 個，當捷徑。
- 暗格 H：3～5 個。
- 可推倒的櫃子 C：室內有幾個門口就挑 4～6 個（純室外可以 0 個）。
- 鬼房 K：1 間，大約 5×5，出口用鐵欄杆門 I，放在地圖中間附近。
- 監獄 J：1 個籠子，J 大約 4×4，籠子外面留 2 圈地面（1 圈放欄杆、1 圈給人站），放在一個有 2 個以上出入口的房間或院子裡，離鬼房遠。
- 出生點 S：3～6 格，在 1F、離鬼房遠的地方。
- 有 2 層的地方：樓梯至少 2 組，離得越遠越好（只有 1 組會變成死路）。

【設計限制】（很重要，違反的話鬼會卡住或玩家會卡關）
- 不能跳：同一層的地面都是同一個高度，沒有台階、沒有高低差（室外也一樣，不要做小山坡）；上下層只能走樓梯。
  樓梯頭尾各留至少 2 格空地。
- 走道至少 2 格寬，門口 1～2 格寬。只靠斜角相連的兩格不算連通。
- 所有地面都要連得到（暗格、鬼房、監獄除外，它們靠門／洞進出）。
- 每個區域（房間或戶外的一塊空地）至少 2 個出口，盡量不要死路。
- 室內房間 6×6～14×14，轉角多、不要太規則。
- 室外不要一大片空地：用 %、高的物件（貨櫃、樹、車、牆）把戶外切成一塊一塊 8×8～16×16 的區域，
  區域之間留 2～3 格寬的出入口。大約每 8 格要有一個能躲的遮蔽物（高度 2 以上）。
- 不管室內室外，都不要有超過 20 格的長直線視野（霧 14 格，鬼看得到前方）。
- 家具／物件：上面不能走（大家都要繞過去），旁邊至少留 1 格走道，不要塞滿（程式還會沿牆隨機放木桶）。
- 不要用地毯、壓力板、半磚、雪片、按鈕、花草之類的東西鋪在地面當裝飾（會影響走路判定）；
  裝飾放牆上、天花板或做成家具／物件。戶外的草地直接用草方塊當地面就好。

【家具／物件】
用小寫字母定義（不能用 h、v），每個寫：字母、名稱、由下往上的 Minecraft 方塊 ID（Java 版 1.21 以後的 ID，幾個方塊就是幾格高；
1 格＝矮，看得過去；2～3 格＝高，擋視線）、會不會發光（戶外的路燈就是會發光的物件）。
例如：t 桌子 spruce_planks 高度1；b 書櫃 bookshelf 高度3；l 路燈 lantern 放在 dark_oak_fence 上 高度3 會發光；
k 貨櫃 orange_concrete 高度3。（不要用半磚、地毯當家具）
大型物件（車、貨櫃、樹）就用同一個字母畫出它佔的那一塊，例如 3×6 的貨櫃畫 18 個 k。

【主題調色盤】
請給：
- 牆、天花板、戶外圍牆／樹籬（%）、矮欄杆（+）的方塊
- 每間室內房間的地板方塊（每間不一樣的顏色，方便認路；清單至少跟房間數一樣多）
- 戶外地面的方塊（可以 2～4 種，說明哪一區用哪一種，例如草地、石磚路、碎石）
- 燈（室內光源方塊）
- 門的材質（木頭種類）

【輸出】
1. 地圖類型、主題名稱、一段簡短說明（氣氛、玩法上的想法：哪裡適合躲、哪裡危險）。
2. 每一層的圖（各一個 code block）。
3. 家具／物件表、調色盤。
4. 自我檢查清單：逐項確認上面【一定要有】和【設計限制】有沒有做到，並寫出每張圖的行數和每行字元數。

地圖類型：＿＿＿＿（室內／室外／室內＋室外）
主題：＿＿＿＿（例如：廢棄醫院／夜間學校／港口貨櫃場／墓園＋教堂／遊樂園＋鬼屋）
```

## 注意的地方（給你看的）

- **讓它自己檢查行寬**：AI 畫格子圖最常錯的是每行長度不一樣、兩層沒對齊。prompt 最後有要它寫行數和每行字元數，可以先看一眼。錯一點點沒關係，我會修。
- **室外最容易出問題的是太空曠**：鬼看得到前方，空地太大人類一定被追到。如果它畫出一大片 `,`，叫它多放 `%` 和高物件。
- **一次一張就好**：叫它一次畫多張容易品質下降。
- **主題可以天馬行空，機制先不要**：主題只會換方塊和物件。它如果提新機制（例如會動的電梯、下雨），我會讀但不會自動做，你決定要不要再跟我說。
- **不用畫木桶、門禁卡、道具**：這些每局隨機。

## 要給我的資訊

1. AI 回的整份文字（存檔丟給我，或直接貼）。
2. 地圖名字（之後用 `/gh build pve <名字>` 之類的指令選圖）。
3. 你自己覺得哪裡想改的（可選）。
