# 房間設計 v2（已實作）

## 整體方案

- **房間格加大**：從 17×17 改成 **20×20**（內部 18×18），每層一樣 3×3 格，井字走廊 3 格寬，整層 **68×68**（含外牆）。
  理由：要在同一間裡同時放「可以繞圈的矮桌區」（看得到彼此的心理戰）和「擋視線的高櫃區」（躲藏），主走道還要維持 2 格寬，15×15 不夠。
- **每間房有自己的完整擺設**，不再是「外圈空走道＋中間圖樣」，所以不會每間都長一樣。
- **門口固定在每面牆正中間**（2 格寬），門口前 4 格寬、2 格深一定空著，所以房間隨便旋轉都能接上走廊。
- **每種房間都混合兩種空間**：低矮可繞圈的「追逐區」和高櫃隔出的「躲藏區」，比例依房間不同（開放辦公室、休息室偏追逐；檔案室、機房偏躲藏）。
- **電源**：每間有 0～2 個電源候選點（`E`）。建議總電源只出現在「電力室」，每棟固定至少一間電力室，玩家會知道要去哪找，但要冒險。
- **風格**：廢棄的現代辦公大樓。牆壁和地板仍依樓層換材質；家具用原版方塊，少量裂紋石磚、苔石、蜘蛛網（蜘蛛網只放天花板，不放走道，因為會讓人變慢）。
- **樓層分配**：1F 公共區（休息室、影印室、儲藏室、廁所、開放辦公室）、2F 辦公區（開放／隔間辦公室、會議室、檔案室、廁所）、3F 設備區（機房、儲藏室、檔案室、廁所、影印室）。每層約 2/3 是該層的房間、其他混搭，同一層不重複。電力室整棟 1～2 間、樓層隨機，避免電源永遠在同一層。
- **細節**：辦公桌上有電腦（陽光感測器）、影印室桌上有紙、吧台上有微波爐和咖啡機、電力室天花板垂下電纜、檔案櫃和貨架中層有變化、天花板角落偶爾有蜘蛛網。都在家具上面或頭頂，不影響走路。
- **走廊**：地上的雜物減半，天花板加一條鐵欄杆通風管；每個門口旁邊掛告示牌（樓層＋房間名稱）。
- **之後再做**：房間之間的蹲伏破洞（企劃書第一版已有規劃，等房間定案後加在相鄰房間的共用牆上）。

所有平面圖都用程式檢查過：四個門口前沒被擋住、每一格走道都走得到、每個容器旁邊都站得到人。
每局房間會隨機旋轉 0／90／180／270 度和鏡像，所以下面的「北」只是圖上的上方。
