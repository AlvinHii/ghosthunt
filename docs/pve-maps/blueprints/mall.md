# 午夜大型廢棄購物中心（Midnight Grand Mall）

* **地圖英文代號（指令用）**：`mall`
* **地圖顯示名稱**：`午夜大型廢棄購物中心`
* **地圖類型**：室內（2 層大型建築，6×6 巨集配置，實際尺寸 **91×91 格**）
* **氣氛與玩法說明**：這是一座停業多年的大型雙層購物中心，整體採「北側雙翼突角＋中段收腰＋南側入口突出」的不規則輪廓。1F 中央 `CORE` 為 31×31 挑高中庭與鬼房 `K`（保全隔離亭），2F 則是一整圈環繞中央挑空的 12 格環狀迴廊商街，靠 3 組遠距樓梯（`STR1`、`STR2`、`STR3`）串聯上下層，全場無任何死路模組。
  * **適合躲藏**：各店鋪與專櫃皆使用不同顏色的地板（書店、服飾店、電玩區、影城、美食街、生鮮超市等），在 14 格濃霧中能靠腳下顏色迅速判位；全館配置 8 個鄰近 `OO` 門口的推倒櫃 `C`、7 處 3×3 實心牆內暗格 `H`、5 個跨模組蹲伏小洞 `h`，以及 3 條跨越 60～85 格的地下檢修通道（`1`、`2`、`3`），非常適合多路線拉扯。
  * **危險地帶**：1F 中央中庭 `CORE` 內就是鬼房 `K`，周邊雖有大理石柱與花台遮蔽，但四面八方共開了 8 個接口，穿過中庭時極易撞鬼；監獄籠子 `J` 設在西北角 `JAIL`（距鬼房約 54 格），開闊且雙面連通，救人時建議利用地下通道 `1` 或 `3` 調虎離山。

## 家具／物件表與主題調色盤

### 家具／物件表（Minecraft Java 1.21+，2026-11-22 重新設計）

每一種家具都是「看一眼就知道是什麼」的組合，而且只放在合理的店裡。共通規則：

* 最底層 `Y+0` 一律是完整方塊、柵欄或牆，不用半磚、樓梯、地毯當底座，所以誰都爬不上去。
* 「視線」欄寫「擋」的家具會擋住視線（2 格以上、實心）；寫「看得過去」的高度只有 1 格，或是細柱、桌腳這類空心結構。
* 視線高度（`Y+1`）不放玻璃、樹葉、鐵欄杆這類真人看得穿、AI 看不穿的方塊。
* 「朝向」欄是轉檔工具放方塊時要遵守的方向規則（見表下的說明）。

| 字母 | 名稱 | 由下往上的方塊（`Y+0` → `Y+1` → `Y+2`） | 高度 | 視線 | 朝向 | 用在哪裡 |
| :---: | :--- | :--- | :---: | :---: | :--- | :--- |
| `a` | 島型展示櫃 | `stripped_birch_wood` → `smooth_quartz` → 頂上放 `decorated_pot`（展示的商品） | 2 | 擋 | 無 | 服飾、鞋店、玩具、百貨、藝廊、運動用品、中庭快閃櫃位 |

**朝向規則**（轉檔工具要支援）：

* **靠牆**：正面朝向離牆最遠的那一側。`b`、`f`、`i`、`m`、`r`、`u`、`x`、`y` 用這條。
* **朝走道**：正面朝向相鄰格子裡空地最多的那一側。`d`、`j`、`q` 用這條；背對背的兩排會自然各朝外。
* **面向桌子或銀幕**：`s` 先找上下左右相鄰的 `g` 或 `d`，面向它；都沒有時面向同一個房間裡最近的 `r`。
* **沿長邊**：`t` 的原木軸向沿著連續長椅的方向；單獨一格就沿房間較長的方向。

**擺放原則**：

* 每間店照它的業態擺：超市用整齊的格狀貨架走道，收銀台在出口旁；服飾、鞋店、百貨是牆邊陳列加中間島櫃的環狀動線；書店是靠牆書架、中間雙面書架、閱讀區；美食街攤位靠牆、中間用餐區；影廳一面銀幕、座位成排面向它；辦公室是桌椅成組、螢幕牆靠牆。
* 收銀台靠近店門口；桌子一定配椅子，椅子一定面向桌子或銀幕。
* 家具之間至少留 1 格；門、開口、暗格入口、地洞口、終端機、電源的前面不放東西。
* 不放跟房間無關的東西，例如拘留廣場不放販賣機、影廳不放貨架。

**參考**：[Store floor plan（Shopify）](https://www.shopify.com/blog/store-floor-plan)、[Store Layout Designs（Lumen Learning）](https://courses.lumenlearning.com/wm-retailmanagement/chapter/store-layout-designs/)、[Minecraft furniture guide（BisectHosting）](https://www.bisecthosting.com/blog/minecraft-furniture-guide-minecraft-cushions-build-hacks-more)、[Getting custom furniture in vanilla Minecraft（Apex Hosting）](https://apexminecrafthosting.com/blog/getting-custom-furniture-in-vanilla-minecraft/)

上面的表是給人看的設計說明，這一段是同一份設計的「機器版」：一行一種家具，`字母 = 方塊（由下往上）| 選項`。
選項：`face=wall`（靠牆，正面朝空地）、`face=aisle`（朝空地最多的一側）、`face=table`（面向旁邊的桌子／櫃檯，沒有就面向銀幕）、
