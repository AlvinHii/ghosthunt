# 午夜購物中心（3～5 人版）

* **地圖英文代號（指令用）**：`mall_m`
* **地圖顯示名稱**：`午夜購物中心（3～5 人版）`
* **地圖類型**：室內（2 層，5×5 巨集配置，實際尺寸 **76×76 格**）
* **來源**：由《午夜大型廢棄購物中心》修正版縮小而來（91×91 → 76×76）。拿掉東北角的 `RM_A`、`RM_B`、`RM_C`、`RM_G`、西南的 `STR3`，2F 只留北側一排；模組內容沒有重畫，只改接口、大門和設施。
* **氣氛與玩法說明**：中段還是 31×31 的挑高中庭 `CORE`（鬼房 `K` 在正中央），四周一圈店鋪。2F 是北側一排長迴廊，兩端各有一座樓梯（`STR1`、`STR2`），可以從 1F 繞一圈再上樓甩開鬼。監獄 `JAIL` 移到西側、接在卸貨庫和服務台之間，有兩個出入口。

## 家具／物件表與主題調色盤

### 家具／物件表（Minecraft Java 1.21+，2026-11-22 重新設計）

每一種家具都是「看一眼就知道是什麼」的組合，而且只放在合理的店裡。共通規則：

* 最底層 `Y+0` 一律是完整方塊、柵欄或牆，不用半磚、樓梯、地毯當底座，所以誰都爬不上去。
* 「視線」欄寫「擋」的家具會擋住視線（2 格以上、實心）；寫「看得過去」的高度只有 1 格，或是細柱、桌腳這類空心結構。
* 視線高度（`Y+1`）不放玻璃、樹葉、鐵欄杆這類真人看得穿、AI 看不穿的方塊。
* 「朝向」欄是轉檔工具放方塊時要遵守的方向規則（見表下的說明）。

**朝向規則**（轉檔工具要支援）：

* **靠牆**：正面朝向離牆最遠的那一側。`b`、`f`、`i`、`m`、`r`、`u`、`x`、`y` 用這條。
* **朝走道**：正面朝向相鄰格子裡空地最多的那一側。`d`、`j`、`q` 用這條；背對背的兩排會自然各朝外。
* **面向桌子或銀幕**：`s` 先找上下左右相鄰的 `g` 或 `d`，面向它；都沒有時面向同一個房間裡最近的 `r`。
* **沿長邊**：`t` 的原木軸向沿著連續長椅的方向；單獨一格就沿房間較長的方向。

**擺放原則**：

* 每間店照它的業態擺：超市用整齊的格狀貨架走道，收銀台在出口旁；服飾、鞋店、百貨是牆邊陳列加中間島櫃的環狀動線；書店是靠牆書架、中間雙面書架、閱讀區；美食街攤位靠牆、中間用餐區；影廳一面銀幕、座位成排面向它；辦公室是桌椅成組、螢幕牆靠牆。
* 收銀台靠近店門口；桌子一定配椅子，椅子一定面向桌子或銀幕。
* 家具之間至少留 1 格；門、開口、暗格入口、地洞口、終端機、電源的前面不放東西。
* 不放跟房間無關的東西，例如拘留廣場不放販賣機、影廳不放貨架。

### 家具設定（給程式讀的；改家具改這裡，`tools/assemble_macro_map.py` 會照這裡蓋）

上面的表是給人看的設計說明，這一段是同一份設計的「機器版」：一行一種家具，`字母 = 方塊（由下往上）| 選項`。
選項：`face=wall`（靠牆，正面朝空地）、`face=aisle`（朝空地最多的一側）、`face=table`（面向旁邊的桌子／櫃檯，沒有就面向銀幕）、
`axis=long`（原木沿長邊）、`front0=`／`front1=`（正面那一格第 0／1 層貼的東西：按鈕、拉桿，或 `item_frame:物品`／`glow_item_frame:物品` 展示框）、
`back1=`（椅背：第 1 層放打開的活板門）、`top=方塊:one`（每一座挑一格放頂上）、`vary0=`／`vary1=`（那一層照位置輪流換方塊）、`books`（雕紋書架插滿書）、`light`（接電源的燈）。
正面那一格放的東西都不擋路；會擋路的（櫃檯的活板門面板、冰箱的鐵活板門）先不放。
