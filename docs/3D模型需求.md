# 《鬼抓人：大樓逃生》3D 模型需求清單

> 給做模型的人（或 AI）看。用 **BetterModel** 插件顯示會動的實體（大鬼、小鬼、直升機……），道具和場景物件用資源包的物品模型。
> 格式、尺寸、動畫名稱照這份做，插件那邊才接得起來。2026-11-23。

## 通用規格

- **工具**：Blockbench，存成 `.bbmodel`（BetterModel 讀這個）。道具、靜態場景物件也可以用 Java 版方塊／物品模型格式（`.json`）。
- **風格**：方塊感、低面數（跟 Minecraft 搭），恐怖但看得清楚輪廓。停電時場景很暗，**重要的部分（鬼的眼睛、讀卡機的燈、螢幕）做成自發光**（emissive）。
- **比例**：1 格 = 16 像素。貼圖每個模型一張，64×64 或 128×128。
- **原點**：在腳底正中間；**正面朝北（-Z）**。
- **檔名**：英文小寫＋底線，例如 `ghost.bbmodel`、`imp.bbmodel`。
- **動畫名稱**：用下面表格裡的英文名稱（插件用名字播放）。會一直播的動畫（idle、walk）要能無縫循環。

## 一、會動的角色（BetterModel，最優先）

### 1. 大鬼 `ghost`

| 項目 | 說明 |
|---|---|
| 大小 | 高 2.2～2.6 格，寬**不超過 0.9 格**（走廊和門口最窄 1～2 格，太寬會穿牆）。實際碰撞箱不變（0.6×1.95），模型只是外觀。 |
| 外型 | 自由發揮（瘦長、駝背、白臉、黑衣……），眼睛自發光；要跟玩家明顯不同。 |
| 變體 | `ghost_nightmare`：夢魘鬼（PvP 會熄燈的那種），同一個骨架換貼圖或多一點東西（例如提燈）。 |

| 動畫 | 什麼時候 | 長度 |
|---|---|---|
| `idle` | 站著（守監獄、守讀卡機、埋伏） | 循環 |
| `walk` | 巡邏（比玩家慢一點） | 循環 |
| `run` | 追人 | 循環 |
| `windup` | 揮拳前搖（舉手） | 0.2～0.5 秒（依難度，插件會調速度） |
| `swing` | 揮拳 | 0.3 秒 |
| `fatigue` | 揮完拳後幾乎走不動（彎腰喘） | 1.5 秒 |
| `roar` | 發現人時吼一聲 | 1 秒 |
| `break` | 拆障礙物、撞開卡住的門、打大小洞（用力敲） | 循環（3.5～4 秒） |
| `pry` | 撬地下通道的活板門（蹲下扳） | 循環（4 秒） |
| `sabotage` | 弄壞大門讀卡機、弄壞貨梯（亂按） | 循環（4 秒） |
| `blinded` | 被煙霧彈打到（摀眼、搖頭） | 3 秒 |
| `flashed` | 被手電筒照臉（用手擋光） | 1.5 秒 |
| `sense` | 感應最近的人在哪（停下來、頭歪一邊） | 1.5 秒 |
| `lights_out` | 夢魘鬼熄燈（舉手） | 1 秒 |

### 2. 小鬼 `imp`

| 項目 | 說明 |
|---|---|
| 大小 | 高約 1 格（半個玩家高），寬 0.5 格以內。 |
| 外型 | 恐怖的小孩：蒼白、黑衣、看不清楚的臉或面具；要一眼看出「不是大鬼」。 |

| 動畫 | 什麼時候 | 長度 |
|---|---|---|
| `idle` | 站著（左右晃、哼歌） | 循環 |
| `walk` | 慢慢走（蹦蹦跳跳也可以） | 循環 |
| `run` | 碰完人逃開、被嚇跑 | 循環 |
| `laugh` | 碰到人時大笑（仰頭、拍手） | 1.5 秒 |
| `mischief` | 關配電箱、關門（伸手推） | 1 秒 |
| `steal` | 搶道具（抓一下藏到背後） | 1 秒 |
| `scared` | 被手電筒照到、煙霧彈打到（摀眼後退） | 1 秒 |
| `appear` | 剛出現（從地上冒出來或從煙裡出來） | 1.5 秒 |

### 3. 直升機 `helicopter`（直升機路線的高潮，可以最後做）

| 項目 | 說明 |
|---|---|
| 大小 | 約 7×3×9 格（停機坪 7×7）。 |

## 三、場景物件（功能方塊的外觀）

功能方塊本身（碰撞、右鍵）不動，3D 模型疊在上面當外觀。**模型大小要跟原本的方塊差不多**（1 格或 1×2 格），不然玩家會以為能穿過去或被擋住。
有狀態的物件要每個狀態一個模型（或一個模型帶動畫）。

## 四、優先順序

1. **大鬼、小鬼**（加上它們的動畫）：影響最大。
2. **手電筒、煙霧彈、門禁卡**：玩家最常拿在手上。
3. **主線的場景物件**：電源、終端機、讀卡機、大門、障礙物、櫃子。
4. **夜半購物城的支線物件**、其他道具。
5. 直升機、度假村機關。

## 五、插件這邊要做的（給實作的 Claude）

- 伺服器裝 **BetterModel**（先確認支援 Paper 26.3），本機 test-server 和 server.pro 都要裝。
- BetterModel 會產生自己的資源包，要跟我們的 `ghosthunt-pack.zip` 合併成一個（或改用 BetterModel 的送包方式）。
- 大鬼、小鬼：實體不變（AI、碰撞箱照舊），把 BetterModel 模型掛上去、原本的外觀隱藏；依 AI 狀態播動畫（追人＝`run`、揮拳前搖＝`windup`……）。
- 道具：物品加 `item_model`（或 custom model data）指到新模型。
- 場景物件：功能方塊不動，上面疊 item display 顯示 3D 模型；狀態改變時換模型或播動畫。
